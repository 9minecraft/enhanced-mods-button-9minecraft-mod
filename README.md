# Enhanced Mods Button — Quickly Open Mod Lists

Enhanced Mods Button 9minecraft Mod puts a dedicated mods button on the main menu and pause screen. This mod helps you open your installed mod list, view mod details, and adjust settings with one click during gameplay or before loading a world. It keeps menu layouts tidy and prevents extra menu buttons from getting pushed off the screen.

Places a full-size Mods button directly on the main title screen and in the in-game pause menu.

## What this build is

An unofficial rebuild of **Fuzs**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
